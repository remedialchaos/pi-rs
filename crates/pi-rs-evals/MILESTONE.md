## Caveats and native adaptations

- Node's `localeCompare` is approximated by case-insensitive ordering with a
  deterministic tie-break; the ASCII identifiers used by the evals sort
  identically. `difference` reproduces 15-significant-digit rounding via
  scientific formatting before reparsing; exact tie cases may differ from JS
  `toPrecision(15)`.
- Integral `f64` metrics serialize as JSON integers (`10`, not `10.0`), matching
  `JSON.stringify`. All other number formatting follows upstream.
- `styleText("bold", ...)` emits ANSI only on a terminal; the Rust formatter
  uses `stdout().is_terminal()` for the same behavior. Test-environment output
  is plain text, matching the recorded upstream golden.
- Rust 2024 forbids unsafe process-global env mutation and privilege changes in
  this crate, so `apply_isolated_environment` returns explicit overrides and
  `resolve_sandbox_identity` validates rather than calling `setuid`; the
  container entrypoint performs the privilege drop. UID/GID env vars in
  `docker_args` are injectable; the production path reads Linux `/proc/self/status`.
- `PiSdkOptions` has no system-prompt injection point, so the initial prompt is
  not forced into the session. `exclude_pi_documentation` and
  `verify_system_prompt` are ported as pure functions with direct tests.
- Upstream `acme-server.test.ts` and `configured-runtime.test.ts` exercise eval
  fixture files (`evals/acme-server.ts`, `evals/configured-runtime.ts`), not the
  five ported source modules, so they are outside this milestone's scope.
- No live Docker build/run was performed (offline verification only); the
  argument vector is verified with an injectable command runner.

## Configurable OCI Container Runtime & Live Rootless Container E2E

- **Configurable OCI runtime (`src/docker.rs`, `src/cli.rs`)**:
  - Preserved `"docker"` as the default command name passed to injectable
    `CommandRunner` mocks (100% drop-in compatibility with existing tests).
  - Added `resolve_container_runtime` / `resolve_host_container_runtime`
    (`PI_EVALS_CONTAINER_BIN` override -> `docker` on `PATH` -> `podman`
    fallback on `PATH`), `SystemCommandRunner::with_container_runtime`, and
    `SystemEvalDockerOps::with_container_runtime`.
  - Documented rootless `podman` 4.9.3 (`crun`) compatibility on `docker_args`.
- **Unit & live E2E tests (`tests/docker.rs`, `tests/docker_live.rs`)**:
  - Added 5 unit tests in `tests/docker.rs` (11/11 total) covering env
    override precedence, `docker` preference, `podman` fallback (including
    skipping non-executable files and directories), missing-runtime errors,
    and `SystemCommandRunner::with_container_runtime`.
  - Added 2 live container E2E tests in `tests/docker_live.rs` (`#[cfg(target_os = "linux")]`):
    100% offline `FROM scratch` images with a pure-Rust static entrypoint
